## 根因与方案

- GitHub 图标：当前 `NavIcon` 使用自绘外圆与近似 Octocat 路径。改为 GitHub 官方 favicon 的 32×32 Invertocat 路径，使用 `currentColor` 适配主题但不改变几何形状。
- 默认背景：布局首屏脚本与显示设置已使用 `solid` 作为缺省值，不改变持久化模型；测试补强默认与恢复默认断言，交付预览恢复纯色。
- 波浪静止：全局减少动效规则通过 `!important` 将动画压缩为一次，随后又显式设置 `animation: none`。移除停止规则，并为波浪提供独立的减少动效覆盖：保持无限循环、放慢周期和降低移动幅度。
- 横幅裁切：用用户新图覆盖现有同名资产；桌面高度提高到约 36rem，首页下推提高到约 29rem，波浪区域提高到约 8rem；新图采用横向 `cover` 与脸部优先焦点。

## 验证方案

- Vitest 检查官方路径、默认纯色、四层周期、减少动效覆盖、横幅高度与新资产尺寸。
- 浏览器对比两次波浪 `transform`，确认实际位移；测量横幅、波浪底部和首页起点。
- 桌面截图核对四张脸，390×844 检查裁切和横向溢出；最后运行 `pnpm check` 与 `git diff --check`。
