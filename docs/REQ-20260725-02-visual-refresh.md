## 目标

用已经确认的阅读画廊 UI 替换正式站点现有页面表现层，使 Eelex Code Hub 成为以内容阅读为中心的个人博客，同时保持原有文章、学习笔记、工具分享、搜索分类、详情页和关于资料不变。

## 范围

- 更新全站设计 token、暖骨白背景、细腻的层次和响应式间距。
- 更新共享圆角导航、页脚、首页个人区、内容发现控件、内容卡片、详情页、关于页和 404 页。
- 首页保留“欢迎来到Eelex 的个人博客”、内容说明、“我的记录与思考”、搜索与分类；分类在左、搜索在右，移动端自然堆叠。
- 分类悬停只使用中性浅色，选中时使用文章蓝、学习笔记暖金、工具分享青绿；内容卡片圆点与分类色对应。
- 关于页使用“关于我”标题和完整原有资料。
- 删除实验室入口、页面与阅读密度交互及其专用测试。

## 非目标

- 不修改 `content/*.mdx`、内容 schema、repository、search 行为、slug、公开资料数据或 GitHub URL。
- 不增加依赖、外部字体、图片、动画库或后端能力。
- 不实现分页、归档、订阅、登录、CMS、评论或部署。

## 验收标准

1. 首页能展示现有全部内容，搜索与四类分类可叠加并保持原有结果行为。
2. 现有每个内容详情页、目录、MDX 正文、关于页和 404 路由仍可访问；公开资料和链接不变。
3. 实验室不出现在导航、首页或路由树，阅读密度代码及专用测试被移除。
4. 桌面和移动端无横向溢出；键盘焦点、跳至主要内容和减少动效支持仍存在。
5. 新视觉符合已确认 demo 的暖纸白、圆角半透明导航、克制层次、分类状态与阅读卡片风格。

## 验证证据

实施前：隔离 worktree 基线 `corepack pnpm test` 为 10 个测试文件、24 项测试通过。

实施中：页面壳契约已完成 RED/GREEN；`corepack pnpm check` 已通过 9 个测试文件、23 项测试、类型检查和生产构建。lint 仅有 `src/content/repository.ts` 的 4 条既有未使用参数 warning。

完成验证：2026-07-25，用户已在本地预览确认阅读画廊 UI、首页与关于页共享标题层级、两处标题/简介玻璃卡片、内容发现与关于页效果均符合预期。最新 `corepack pnpm check`、`git diff --check` 再次通过；生产构建路由仅包含 `/`、`/about`、`/_not-found` 与 3 个静态内容详情页，`/lab` 已不存在。

## 完成结果

- 原有文章、学习笔记、工具分享、搜索/分类、详情目录、关于资料和 GitHub 链接均保持不变。
- 首页和关于页的大标题与简介共享同一组字号、字重、行高和间距，并使用同一种暖白半透明玻璃卡片。
- 实验室入口、`/lab` 页面、阅读密度交互及专用测试已移除。
- 未执行推送、部署、远程 CI 或线上 Netlify 核对；这些操作不在本 REQ 实施范围内。
