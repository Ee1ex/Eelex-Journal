## 目标

修正 GitHub 图标来源、横幅默认状态、波浪静止和壁纸裁切问题，使可选横幅模式在桌面端具有接近参考站的首屏深度，并完整保留新壁纸中四位人物的脸部。

## 范围

- GitHub 入口使用 GitHub.com 官方 Invertocat 图标，不再使用自绘近似图标。
- 无保存偏好和恢复默认时使用纯色背景；保留用户主动选择后的本地持久化。
- 波浪保持四层 7、10、13、20 秒无限循环；减少动效环境改为更慢、更柔和的持续移动，不再完全静止。
- 使用用户本次上传的 1200×521 新壁纸替换横幅资产。
- 桌面横幅与内容下推深度对齐参考站约 565px 的波浪底部位置，并调整裁切焦点，保证四位人物脸部可见。

## 非目标

- 不改变主题、文章、搜索、菜单、内容模型或移动端信息结构。
- 不热链 GitHub 或参考站图片，不复制参考站品牌和正文。
- 不推送远程或部署。

## 验收标准

1. GitHub 项目入口显示 GitHub 官方 Invertocat 路径，无自绘外圆。
2. 新访客与恢复默认均为纯色背景，用户选择横幅后仍可持久化。
3. 四层波浪在当前浏览器环境均产生可测量的持续位移，速度与参考站同量级。
4. 桌面横幅底部接近 565px，新壁纸四位人物脸部均在可见区域。
5. 390×844 无横向溢出，纯色与横幅模式切换正常。
6. 自动化检查与浏览器桌面/移动端验收通过。
