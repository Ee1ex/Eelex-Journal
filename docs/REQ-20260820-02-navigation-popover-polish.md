## 目标

修正已完成知识库界面的导航对齐、弹层互斥与信息分组，并使用 Eelex 当前 GitHub 公开头像，使顶部导航更整洁且不会发生弹层遮挡。

## 范围

- 顶部导航卡片左右边缘与首页三栏内容的外边缘对齐。
- “项目”“关于”“显示”和移动菜单使用同一受控弹层状态；点击空白、聚焦其他控件、打开另一菜单或按 `Escape` 时关闭旧弹层。
- “归档”收进“项目”下拉菜单；“反馈”收进“关于”下拉菜单，桌面导航不再单独占位。
- 使用 `https://github.com/Ee1ex` 当前公开头像的本地副本，并同步替代文本。
- 公告始终显示，不提供关闭按钮。

## 非目标

- 不改变文章内容模型、日期、搜索、主题选项、归档页面或反馈目标地址。
- 不新增依赖、后台、账号写入、远程推送或部署。
- 不删除旧头像文件；待用户后续明确确认后再决定是否清理未引用资产。

## 验收标准

1. 桌面导航卡片与下方三栏内容左右对齐。
2. 任一导航弹层打开后，打开另一弹层会关闭前者；点击导航外空白、聚焦搜索等其他控件或按 `Escape` 会关闭当前弹层。
3. 桌面顶层仅保留“首页、项目、关于、搜索、显示”；归档位于项目菜单，反馈位于关于菜单。
4. 首页与关于页显示从 GitHub 公开资料获取的 Eelex 头像本地资产。
5. 公告没有关闭按钮，刷新和交互后继续显示。
6. 自动化检查、桌面浏览器交互与布局测量通过。

## 完成记录与验证证据

- 导航改为与首页共用 `90rem` 外层和 `page-inline` 内边距基线；浏览器测量导航与三栏内容的左、右边缘差值均为 `0px`。
- 项目、关于、显示和移动菜单共用单一受控状态；浏览器验证打开“显示”后项目菜单节点数量为 0，点击空白、聚焦搜索或按 `Escape` 后当前弹层节点数量均为 0。
- 项目菜单包含“内容归档”和 GitHub 项目；关于菜单包含“关于 Eelex”和“反馈与联系”，桌面顶层不再显示独立归档或反馈按钮。
- 从用户授权浏览器中的 `https://github.com/Ee1ex` 读取公开头像地址，并将真实 413×413 PNG 保存为 `/ee1ex-github-avatar.png`；首页与关于页均通过统一资料源使用该资产。

- 390×844 移动端菜单包含同样的信息分组，`scrollWidth === clientWidth`；点击页面空白后菜单关闭。
- `pnpm check` 通过：13 个测试文件、40 项测试、格式、类型、Lint 与静态构建均成功；仍有 4 条既有非阻塞 ESLint warning。
