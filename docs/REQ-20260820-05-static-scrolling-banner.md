# REQ-20260820-05：静态滚动横幅与底部渐隐

- 状态：Done

- 更新日期：2026-08-20

- 批准来源：用户于 2026-08-20 明确要求取消波浪，并让横幅随页面滚动消失。

## 目标

将可选横幅模式简化为静态图片与主页背景色渐隐，使横幅属于页面顶部内容而不是固定背景。

## 范围

- 继续使用用户指定的 `56652667_p0_master1200.jpg` 对应横幅资产。
- 完整移除四层 SVG 波浪、动画关键帧及减少动效专用波浪规则。
- 横幅底部使用与当前主题画布颜色一致的渐变过渡。
- 横幅从固定定位改为页面顶部绝对定位，随文档滚动向上并离开视口。
- 默认纯色背景与用户横幅偏好持久化保持不变。

## 非目标

- 不改变横幅高度、图片焦点、导航、文章列表、主题或内容模型。
- 不推送远程或部署。

## 验收标准

1. 横幅组件中不存在 SVG、`use` 或波浪结构，样式中不存在波浪关键帧。
2. 横幅底部平滑过渡为 `--eelex-color-canvas`。
3. 横幅使用非固定定位；向下滚动超过横幅高度后，图片完全离开视口。
4. 纯色与横幅模式切换正常，桌面和 390×844 无横向溢出。
5. 自动化检查与浏览器验收通过。

## 覆盖记录

- 本需求替代 `REQ-20260820-04` 中所有持续波浪要求；其余已完成项目继续有效。

## 完成与验证

- 横幅组件仅保留图片层与渐隐层，SVG、`use`、波浪选择器和两套关键帧均已移除。
- 底部渐隐在亮色与暗色主题中分阶段混合到 `--eelex-color-canvas`，最终 100% 与主页背景一致。
- 横幅定位已由 `fixed` 改为 `absolute`；浏览器滚动到 636px 时，576px 横幅底部为 `-60px`，完全离开视口。
- 指定图片与现有横幅资产 SHA-256 一致，未重复覆盖或生成图片。
- 桌面与 390×844 浏览器验收通过，移动端无横向溢出；`pnpm check` 通过，13 个测试文件、44 项测试及 12 个静态页面构建成功。
- 未删除文件，未推送、部署、发送消息或修改账号权限。
