## 背景

Eelex Code Hub 是用于学习完整 Web 开发流程的第一个个人项目。它既要支持持续发布内容，也要承担个人资料展示和前端设计能力展示，但不能因“顺手加功能”演变成内容平台或社区产品。

## 已批准决策

| 决策主题 | 已选方案 | 未选方案 | 选择理由与影响 |
| --- | --- | --- | --- |
| 项目目标 | 学习优先 | 内容品牌优先、作品集优先 | 先跑通完整流程，同时让产出具备公开展示价值 |
| 品牌名称 | Eelex Code Hub | Eelex Dev Studio、Eelex Code Journal | 能覆盖编程、设计、内容和个人资料；公开文案需明确是个人空间而非社区 |
| 首页主次 | 内容优先，个人资料位于顶部 | 大幅个人 Hero、资料与内容完全并重 | 保证访客优先发现文章，同时保留小型在线简历能力 |
| 项目页面 | v1 不设独立项目页 | 独立作品集 | 当前没有可展示项目，博客本身即第一个展示作品 |
| 内容类型 | 文章、学习笔记、工具分享共用模型 | 独立工具库、外链目录 | 降低内容结构和页面维护成本 |
| 首页与列表 | 首页展示最新内容，另设全部文章页 | 首页承载全部内容、仅归档页 | 首页保持聚焦，全部文章页承担完整浏览和筛选 |
| 实验室 | 保留独立、可删除的实验室 | 不设实验页、仅文章内演示 | 直接展示 UI 和动效学习成果，同时避免污染核心阅读链路 |
| 关于我 | 独立页面 | 只在首页展示资料 | 首页保持简洁，关于页承载完整基础资料 |
| 内容发现 | 分类或标签筛选 | 搜索、纯时间列表 | v1 保留必要发现能力，不引入搜索复杂度 |
| 前端路线 | Next.js + TypeScript + Tailwind CSS + MDX | Nuxt、原生 HTML/CSS/JS | 与博客的 SEO、内容和前端学习目标匹配 |
| 内容维护 | 项目内本地 MDX | 在线 CMS、Notion 同步 | 无需数据库和登录，Git 即发布入口 |
| 部署平台 | Netlify | Vercel | 用户希望使用 Netlify Free 完成早期部署；部署阶段需重新核验计费和地区可访问性 |
| 独立域名 | 不作为 v1 门槛 | v1 强制购买并绑定 | 先用平台子域名完成上线闭环 |
| 访问地域 | 兼顾中国大陆与海外 | 仅大陆、仅海外 | 避免使用可能在部分地区不可用的关键外部资源，并在上线前实测 |
| 内容语言 | 仅中文 | 中英双语、英文文章混用 | 控制 v1 内容与界面复杂度 |
| 访问统计 | Netlify 基础用量和短期流量数据 | Google Analytics、其他第三方统计、不做统计 | 不额外集成脚本，先满足基础观察需要 |
| 上线内容门槛 | 至少一篇真实内容 | 至少三篇、不设门槛 | 更快完成首次上线，同时避免空站点 |
| 详情页 | 标准阅读能力 | 增强阅读能力、极简详情 | 支持技术内容所需的图片、代码块和文章目录 |
| 内容封面 | 可选封面 | 纯文本、强制封面 | 兼顾视觉展示与低成本发布 |
| 视觉主题 | 单一主题 | 自动或手动深色模式 | 先把一套主题的设计和阅读体验做好 |
| 联系方式 | 外部联系链接 | 站内表单、不提供联系 | 避免表单、后端和垃圾信息处理 |
| RSS 与订阅 | v1 不提供 | RSS、邮件订阅 | 当前内容量和用户规模不足以支撑订阅系统价值 |
| 基础网站能力 | 响应式、基础 SEO、sitemap、robots、404、自动部署 | 增加 RSS、延后 SEO | 这些能力属于公开博客的最低上线质量 |
| GitHub README | Phase 0 建立准确基础版，Phase 7 专门设计展示版 | Phase 0 提前制作视觉稿 | 最终展示必须基于真实页面、截图和上线地址 |

## Netlify 外部条件

截至 2026-07-24，Netlify 官方资料显示 Free 方案提供每月 300 credits，并设置硬上限。该额度适合早期低流量项目是当前判断，不是长期保证。

- 官方计费说明：<https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/credit-based-pricing-plans/>
- 官方定价：<https://www.netlify.com/pricing/>

Phase 7 部署前必须重新核验：

- Free 方案的当前额度和计费方式
- 生产部署、带宽和请求的 credits 消耗
- 额度耗尽后的站点行为
- 中国大陆与海外的实际访问情况
