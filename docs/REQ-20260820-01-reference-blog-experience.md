## 目标

在保留本地 MDX、静态导出、现有内容 URL、分类搜索和可访问性基线的前提下，将 Eelex Code Hub 改造为参考 `https://blog.aixiaobo.cn/` 的知识库式访客体验，并结合用户提供的单色设计 token。首页文章固定使用带封面的单列布局。

## 范围

- 统一顶部导航、移动端菜单、即时搜索入口、显示设置和页脚。
- 首页采用桌面三栏：个人与发现侧栏、单列文章流、站点统计；移动端收拢为单列。
- 文章卡片展示封面、标题、摘要、发布日期、分类、标签；无封面时使用项目内真实默认资产。
- 新增静态归档页、完整搜索结果页和 RSS。
- 文章详情增加预计阅读时间、复制链接、上一篇/下一篇、桌面/移动目录与返回顶部。
- 保留亮色、暗色、跟随系统，以及横幅壁纸/纯色背景；不提供全屏透明壁纸和列表/网格切换。
- 保留项目/产品链接入口；反馈仅使用邮箱或公开联系方式，不建设评论或联系表单。
- 正文商业合作模块与商店入口只记录为未来可选扩展，不在当前公开页面渲染。

## 非目标

- 不复制参考站的文章、头像、品牌标识、统计数字、商业链接或个人信息。
- 不建设 CMS、数据库、自建后端、登录、评论、点赞、收藏、订阅或在线封面上传后台。
- 不实现日历、日期日历标记或通过日历跳转；文章发布日期继续完整展示。
- 不实现分享海报、API 中转链接、正文充值购买导航、全屏透明壁纸或网格布局。
- 不推送远程、不部署生产、不修改 Netlify 或账号配置。

## 验收标准

1. 首页桌面为三栏知识库结构，文章区为单列封面卡片；手机端无水平溢出。
2. 文章发布日期在首页、搜索、归档和详情页均可见，且不存在日历 UI。
3. 搜索、分类和标签筛选可用；归档按年份分组。
4. 文章详情可复制当前链接，提供阅读时间、目录、上一篇/下一篇和返回顶部。
5. 亮色、暗色、跟随系统、横幅壁纸和纯色背景可操作并具备减少动效保护。
6. 项目/产品链接与反馈联系方式来自公开资料配置；无评论系统或联系表单。
7. 现有 MDX 内容、静态路由、SEO、404 与静态导出保持可用。
8. `pnpm check`、`git diff --check`、桌面与 390×844 浏览器验收通过。
