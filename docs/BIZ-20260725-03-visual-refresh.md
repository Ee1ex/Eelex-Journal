## 决策

将用户已确认的“阅读画廊”视觉方案迁移至正式站点：暖骨白背景、半透明圆角导航、克制的墨色文字、分类色仅用于小面积状态、宽松但不过度的阅读节奏。

保留首页全部内容发现、文章详情、关于页、404、公开资料、文章/学习笔记/工具分享及其原有 MDX 内容；不改变搜索和分类的匹配逻辑、内容 URL、外部链接或内容模型。

用户明确决定移除实验室，因此正式站点不再展示实验室导航、首页入口、`/lab` 页面或阅读密度交互。

首页与关于页的“标题＋简介”使用统一字号层级，并置于相同的暖白半透明玻璃卡片中；此处只强化阅读起点，不改变内容发现或个人资料的结构。

## 理由

- 现有内容需要更聚焦的个人阅读空间，而不是多处独立入口。
- 已确认 demo 已通过多轮视觉校正，能够直接作为正式表现层的验收基线。
- 实验室与博客核心内容链路独立，移除后不影响首页、内容详情、关于页和 404 的可用性。

## 非目标

- 不重写、增删或迁移 MDX 正文及 frontmatter。
- 不引入新字体、图片资源、UI 依赖、后端、CMS、登录、评论、订阅、分页或 URL 状态。
- 不推送、部署、创建 PR 或更改 Netlify 设置。

## 验收依据

- 首页、详情、关于页、404 和内容发现保留可访问的语义与原有内容。
- 实验室没有导航入口、首页入口、路由页面或阅读密度实现残留。
- 视觉细节与用户确认的 demo 一致：导航、首页标题、分类状态、内容卡片、关于页和页脚均遵循新风格。
